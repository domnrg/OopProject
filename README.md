# OopProject

Проект демонстрирует основы объектно-ориентированного программирования (ООП) на языке Python.

## Описание

В рамках проекта реализованы два класса:

- `Product` — модель для описания товара.
- `Category` — модель для категории товаров, содержащая список продуктов.

Также в проекте реализованы:

- учёт количества созданных категорий и товаров;
- приватные атрибуты и свойства с геттерами/сеттерами;
- статические и классовые методы;
- методы сравнения и модификации товаров;
- валидация и защита от некорректных значений (например, цены ≤ 0);
- система тестирования с использованием `pytest`;
- автоматические фикстуры (`conftest.py`);
- проверка стиля кода с помощью `flake8`;
- отчёт по покрытию кода (`pytest-cov`).

## Расширенная функциональность

- наследование: специализированные классы `Smartphone` и `LawnGrass`, унаследованные от `Product`;
- переопределение строкового представления `__str__()` для читаемого вывода товаров и категорий;
- запрет на добавление в категорию объектов, не являющихся `Product` или его наследниками;
- поддержка сложения товаров (`__add__`) с проверкой на совместимость типов;
- защита от сложения объектов разных типов с выбрасыванием `TypeError`;
- подтверждение на понижение цены при установке через `input()` (в `@price.setter`);

## Структура классов

### Класс `Product`

Атрибуты:
- `name` — название продукта;
- `description` — описание;
- `price` — цена (приватный);
- `quantity` — количество на складе.

Методы:
- `new_product` — создание или обновление товара по словарю;
- `@property price` и `@price.setter` — геттер/сеттер с валидацией;
- `__str__` — строковое представление продукта;
- `__add__` — сложение стоимости двух товаров одного типа;
- `new_product` — создание нового товара из словаря;
- `merge_products` — объединение товара с уже существующим;
- `@property price` и `@price.setter` — управление ценой с валидацией.

### Класс `Category`

Атрибуты:
- `name` — название категории;
- `description` — описание;
- `products` — список продуктов (приватный);
- `category_count` — общее число созданных категорий (атрибут класса);
- `product_count` — общее число продуктов во всех категориях (атрибут класса).

Методы:
- `add_product` — добавление продукта;
- `@property product_list` — список товаров в читаемом виде.
- `middle_pice` - метод подсчета среднего ценника всех товаров в классе

### Классы наследники `Smartphone` и `LawnGrass`

- `Smartphone` — наследует Product, дополнительно содержит поля: efficiency, model, memory, color.
- `LawnGrass` — наследует Product, дополнительно содержит поля: country, germination_period, color.

### Класс `BaseProduct`

Абстрактный базовый класс

### Миксин `MixinRepr`

Автоматически отображает информацию при создании объекта
