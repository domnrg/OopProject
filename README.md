# OopProject

Проект демонстрирует основы объектно-ориентированного программирования (ООП) на языке Python.

## Описание

В рамках проекта реализованы два класса:

- `Product` — модель для описания товара.
- `Category` — модель для категории товаров, содержащая список продуктов.

Также в проекте реализованы:

- учёт количества созданных категорий и товаров;
- приватные атрибуты и свойства с геттерами/сеттерами;
- статические и классовые методы;
- методы сравнения и модификации товаров;
- валидация и защита от некорректных значений (например, цены ≤ 0);
- система тестирования с использованием `pytest`;
- автоматические фикстуры (`conftest.py`);
- проверка стиля кода с помощью `flake8`;
- отчёт по покрытию кода (`pytest-cov`).

## Структура классов

### Класс `Product`

Атрибуты:
- `name` — название продукта;
- `description` — описание;
- `price` — цена (приватный);
- `quantity` — количество на складе.

Методы:
- `new_product` — создание или обновление товара по словарю;
- `@property price` и `@price.setter` — геттер/сеттер с валидацией;
- и другие.

### Класс `Category`

Атрибуты:
- `name` — название категории;
- `description` — описание;
- `products` — список продуктов (приватный);
- `category_count` — общее число созданных категорий (атрибут класса);
- `product_count` — общее число продуктов во всех категориях (атрибут класса).

Методы:
- `add_product` — добавление продукта;
- `@property product_list` — список товаров в читаемом виде.
